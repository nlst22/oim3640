# Week 13 (April 23, 2026) - Data Science, Machine Learning, and AI with Python

## What I learned this week
- Python can be used for many different areas of data work:
  - data manipulation
  - visualization
  - machine learning
  - deep learning
  - LLMs and AI applications
- `numpy` is useful for numerical computing
- `numpy` works with arrays and mathematical operations
- `pandas` is useful for organizing and analyzing data in tables
- DataFrames are similar to spreadsheets or tables
- `pandas` can be used to filter, group, merge, and analyze data
- `polars` is another data library that is faster for large datasets
- `matplotlib` is used to create visualizations in Python
- Other visualization tools include:
  - `seaborn`
  - `plotly`
  - `bokeh`
- `scikit-learn` is used for machine learning
- Machine learning tasks can include:
  - regression
  - classification
  - clustering
- Deep learning frameworks include:
  - PyTorch
  - TensorFlow
  - JAX
- PyTorch seems especially important because it is widely used in both research and industry
- Python can also be used with LLM APIs to build AI-powered apps
- LLM applications can include agents, RAG systems, and tools that use external knowledge
- Prompt engineering matters because the quality of the input affects the quality of the output
- Useful prompt strategies:
  - clear instructions
  - context
  - examples
  - role/system prompts
  - temperature control
- Python tools like Jupyter Lab, Google Colab, and Kaggle Notebooks are useful for practicing data science and machine learning
