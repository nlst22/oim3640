## What I learned today
Learned how file I/O works in Python, including reading and writing files using open()
Understood why using with open(...) is better, since it automatically closes files and prevents errors
Learned different ways to read files:
read() for full content
looping line-by-line for large files
Learned how to write and append to files, and the risk of overwriting when using "w" mode
Introduced to CSV files, including:
Reading with csv.DictReader()
Writing with csv.DictWriter()
Learned how JSON works as a data format:
json.load() vs json.loads()
json.dump() vs json.dumps()
Understood how to save and load structured data (lists/dictionaries) using JSON
Learned how to work with APIs using requests.get() and convert responses into JSON
Saw how to do a full data pipeline (API → JSON → file → analysis)
Brief introduction to YAML and SQLite as other ways to store/manage data
