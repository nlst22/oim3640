## What I learned today
[Brief reflection on key concepts; focus on understanding, not just syntax]
* Learned about iteration and how loops allow programs to repeat actions efficiently.
* Understood the difference between for loops and while loops.
* for loops iterate over a known sequence or a known number of times.
* while loops continue running until a condition becomes false. 
* Learned when to use a while loop, such as when waiting for user input (e.g., continuing until the user types "quit"). 
* Learned how break stops a loop immediately and continue skips to the next iteration. 
* Practiced looping through strings, where Python iterates through each character in a word. 
* Learned the search pattern, where a loop checks each element in a sequence and returns True if a condition is found. 
* Learned that the in operator can simplify search loops by checking directly if a character exists in a string.
