## Overall Reflections

This course helped me become more confident with problem solving and software design in Python. Before this class, I understood some basic programming concepts, but I did not always know how to turn those concepts into a complete project. Over the semester, I learned how to break larger problems into smaller steps, write functions, organize code, work with data, use APIs, build Flask apps, and think about how software works beyond just the code itself.

One of the biggest things I learned was how important structure is when building a program. In the beginning, I was mostly focused on getting the code to work, but as the class went on, I started thinking more about how the code is organized, whether the functions are clear, and how a user would actually interact with the program. Projects like the bill splitter helped me understand how input validation, menus, functions, and error handling all come together to create a smoother user experience.

I also learned how Python can connect to real-world tools and applications. Working with APIs showed me that programs can pull in outside data and respond dynamically instead of only working with fixed information. Flask was especially useful because it helped me understand the difference between a regular Python script and a web application. I learned how routes, forms, templates, and backend logic work together to create a full-stack app.

Another important takeaway was the importance of debugging and persistence. I often ran into errors with file paths, missing packages, logic issues, or code not behaving the way I expected. At first, these errors felt frustrating, but I gradually became better at reading error messages, testing small pieces of code, and figuring out where the issue was coming from. This made me realize that debugging is not separate from programming, it is a major part of the process.

The course also helped me think more seriously about responsible software development. Learning about API key security, `.env` files, `.gitignore`, and deployment showed me that building software is not just about functionality. It also involves protecting sensitive information, preparing code for production, and thinking about how others will access and use the application.

AI was also a useful part of my learning process. I used AI to clarify concepts, explain errors, and help me understand unfamiliar tools or syntax. However, I also learned that AI output needs to be checked, edited, and tested. I also learned about CODEX and how it aid in building. 

Overall, this course gave me a stronger foundation in Python and software design. More importantly, it helped me see coding as a process of problem solving, iteration, and communication. I now feel more comfortable approaching technical projects, even when I do not know the full solution at the beginning. Going forward, I want to keep building on these skills, especially with web apps, APIs, and AI-powered tools.
